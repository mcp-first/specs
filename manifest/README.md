# The MCP-first Manifest

The complete MCP-first manifest, in Markdown.

- [`manifesto.md`](manifesto.md) — the positioning, the thesis, and the ten principles.
- [`specification.md`](specification.md) — the normative specification: 40 conformance
  rules (R1–R40, RFC-2119), the risk model, the output contract, and conformance levels.

A machine-readable edition of the specification is served at
<https://mcp-first.ai/manifest.ai>.
